# Personal-Finance-Tracker-App


## Overview
The **Personal Finance Tracker** is a user-friendly application designed to help individuals manage their finances efficiently. It enables users to track income, expenses, savings, and budgeting goals. This app is perfect for anyone looking to gain better control of their financial life.

## Features
- **Add and Categorize Transactions:** Easily record income and expenses by category (e.g., food, transportation, entertainment).
- **Budgeting Tools:** Set monthly budgets and track spending against them.
- **Savings Goals:** Set and monitor progress towards specific financial goals.
- **Transaction History:** Access detailed logs of past transactions.
- **Secure Access:** User authentication ensures data privacy and protection.

## Technology Tools
- **Frontend:** React.js,Type Script,CSS,Javascipt.
- **Backend:** Node.js with Express.
- **Database:** MongoDB for storing financial data.
- **Authentication:** Clerk for secure login and session management.
- **Hosting:** Vite.

## Usage
1. **Sign Up / Log In:** Create an account or log in to an existing one.
2. **Add Transactions:** Input income or expenses with descriptions and categories.
3. **Set Budgets:** Define monthly spending limits for each category.
4. **View Insights:** Access visualized data for spending patterns and progress towards savings goals.
5. **Adjust Goals:** Update budgets and goals as your financial situation changes.
